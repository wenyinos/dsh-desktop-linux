安装 Install

# Debian / Ubuntu
sudo apt install ./deepseek-harness-<version>-linux-amd64.deb

# Fedora / RHEL / openSUSE
sudo dnf install ./deepseek-harness-<version>-linux-x86_64.rpm

# FreeBSD 15
sudo pkg install ./deepseek-harness-<version>-freebsd-x64.pkg

请按 CPU 架构选择文件：x86_64 / amd64 对应 x64，aarch64 / arm64 对应 arm64。 FreeBSD 包的依赖（含 Electron 运行时）由 pkg 自动解析。

包内包含 Included

  • 自带 Node 与 pnpm，无需另外安装
  • 安装 dsh 命令并加入 PATH
  • 桌面图标与菜单项
  • Office 文档转换能力（仅 Linux）

FreeBSD 说明 FreeBSD notes

  • 随 FreeBSD 版 Electron 运行时构建，依赖（含 Electron）由 pkg 从 FreeBSD 仓库自动解析
  • 暂不包含 Office 文档转换与图像处理：相关依赖没有 FreeBSD 版本
  • 暂不包含 Python 运行时载荷与沙箱功能；自带 Node 与 pnpm、命令行与插件管理仍可正常使用

不包含 Not included

  • 应用内自动更新 —— 升级请安装新版本的包
  • 代码签名 —— 首次安装时系统可能提示来源未知

自动构建 Automated

  • 每日检查上游最新版本，有新版本即自动构建
  • 始终基于上游源码构建，不改动上游代码
  • Linux 双架构与 FreeBSD 包构建成功后统一发布；已发布的版本不会重复构建
