DSH Desktop 打包

为 DeepSeek Harness 构建 Linux 与 FreeBSD 桌面安装包

非官方构建 · Unofficial build

上游只提供 macOS 与 Windows 桌面版。本仓库自动跟踪上游版本， 构建 Linux 与 FreeBSD 安装包并发布，无需手动同步源码。

自动构建 Automated

  • 每日检查上游最新版本，有新版本即自动构建
  • 始终基于上游源码构建，不改动上游代码
  • Linux 双架构与 FreeBSD 构建成功后统一发布，已发布的版本不会重复构建

安装 Install

sudo apt install ./deepseek-harness-<version>-linux-amd64.deb
sudo dnf install ./deepseek-harness-<version>-linux-x86_64.rpm
sudo pkg install ./deepseek-harness-<version>-freebsd-x64.pkg

包内包含 Included

  • 自带 Node 与 pnpm，无需另装
  • 安装 dsh 命令，已加入 PATH
  • 桌面图标与菜单项
  • Office 文档转换能力（仅 Linux）

不包含 Not included

  • 应用内自动更新，升级请安装新版本包
  • 代码签名，首次安装可能提示来源未知
  • FreeBSD 版暂不含 Office 转换与图像处理
